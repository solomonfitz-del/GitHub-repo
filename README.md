# SiteForge
Automated website generation pipeline for local businesses without an online presence.

## Pipeline
1. Leads scraped from Google Places (no website = target)
2. Demo site auto-generated from lead data
3. Demo auto-deployed to hosting
4. Cold email sent with demo link via Hunter.io + email API
5. Reply classification + auto-response via LLM
6. Payment handling via Stripe
7. Production build + domain registration + deployment
